# C言語 基礎プログラミング

## 概要
学校の課題や自主学習を通じて、C言語の基礎からメモリアクセスまでを泥臭く書き上げたソースコード集です。
プログラミングの基礎体力を固めるとともに、個人でGit/GitHubを用いたバージョン管理の練習としてリポジトリ化しました。

## 学習・実装した主な内容
* **基本構文と制御工学:** 変数、入出力、条件分岐、ループ処理、整列処理、多分岐構造
* **関数と分割代入:** 処理のモジュール化と再利用性の向上
* **ポインタとメモリアドレス:** C言語特有のメモリ管理の基礎
* **配列と文字列操作:** データ構造の基礎的な扱い

## 目的
* C言語を通じた、コンピュータの低レイヤーな動作原理の理解
* エラー（セグメンテーションフォルト等）の自力解決を通じたデバッグ能力の向上
* 大量のコードを書き捨てるのではなく、バージョン管理ツール（Git）で資産として管理する習慣づけ

## 実行環境
* OS: Windows / Linux
* コンパイラ: GCC
